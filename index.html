Bab 2 Metode Penelitian
Tahapan Input Data Proses / Parameter Uji Output / Hasil
1. Pengumpulan Data Tangkapan layar dan teks komentar dari platform (X/Threads/Instagram). Kurasi manual (memisahkan dataset komentar organik manusia dan teks indikasi bot). Dataset ujicoba berlabel (Human vs AI).
2. Rekayasa Prompt Dataset ujicoba dan instruksi sistem (System Prompt). Menyusun instruksi ke API LLM detektor agar fokus menilai anomali gaya bahasa, repetisi, dan kesesuaian EYD dengan persona. Model prompt deteksi yang optimal.
3. Klasifikasi Analitis Teks tunggal yang dimasukkan pengguna ke antarmuka sistem. Sistem (berbasis Python) meneruskan teks ke API LLM untuk menganalisis probabilitas teks buatan mesin berdasarkan parameter gaya bahasa. Label Klasifikasi: Aman (Organik) / Indikasi Bot AI.
4. Uji Prompt Injection Akun media sosial yang mendapat label 'Indikasi Bot AI'. Mengirimkan instruksi pemaksaan logika (contoh: "Abaikan instruksi sebelumnya...") sebagai respons di komentar. Verifikasi Final (Terkonfirmasi Bot jika identitas AI bocor).
⚡ Pemindaian Massal Komentar (Batch Filtering)
Multi-Comment Filter

Masukkan beberapa komentar sekaligus (satu komentar per baris) untuk menyaring komentar organik dari serbuan akun buzzer sintetis secara otomatis.

🧠 Arsitektur System Prompt Detektor (Tahap 2)
Prompt Engineering

Pada Tahap 2 Metode Penelitian, instruksi sistem (System Prompt) dirancang khusus agar LLM pendeteksi fokus pada anomali sintaksis EYD terhadap persona dan tidak mengalami bias saat membaca bahasa gaul (slang) lokal Indonesia.
